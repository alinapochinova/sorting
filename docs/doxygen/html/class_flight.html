Detailed Description

Класс, представляющий информацию об авиарейсе

Содержит все необходимые поля для описания рейса, а также перегруженные операторы сравнения для сортировки.

Invariant
passengers >= 0 (число пассажиров неотрицательное)
arrivalDate в формате YYYY-MM-DD
arrivalTime в формате HH:MM:SS

Оператор "меньше" для сортировки

Parameters
otherОбъект для сравнения
Returns
true если текущий объект должен идти раньше other

Правила сравнения (по приоритету):

  1. Сравнение по дате прилета
  2. При равенстве дат - по времени прилета
  3. При равенстве времени - по названию авиакомпании
  4. При равенстве авиакомпании - по числу пассажиров (по убыванию!)
Note
Число пассажиров сравнивается в обратном порядке (убывание), чтобы при сортировке по возрастанию рейсы с бОльшим числом пассажиров шли первыми.
