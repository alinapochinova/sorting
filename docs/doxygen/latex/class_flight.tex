\doxysubsection{Detailed Description}
Класс, представляющий информацию об авиарейсе 

Содержит все необходимые поля для описания рейса, а также перегруженные операторы сравнения для сортировки.

\begin{DoxyInvariant}{Invariant}
passengers \texorpdfstring{$>$}{>}= 0 (число пассажиров неотрицательное) 

arrival\+Date в формате YYYY-\/\+MM-\/\+DD 

arrival\+Time в формате HH:\+\+MM:\+SS 
\end{DoxyInvariant}
